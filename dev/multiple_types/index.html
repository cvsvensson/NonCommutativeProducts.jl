Multiple types

Several types can be used in the same expressions. When sorting, mul_effect is called on every pair of neighbouring factors, so each pair of types that can end up next to each other needs one. For types that commute with each other, the macro @commutative defines mixed arithmetic and the mixed mul_effects for you. Factors are then ordered by type, in the order the types are listed.

julia> import NonCommutativeProducts: @commutative, @ncjulia> struct Foo endjulia> struct Bar endjulia> @nc Foo Barjulia> @commutative Foo Barjulia> 2Bar()Foo() - Foo()Bar() |> sortFoo()*Bar()

For types that don't commute, define mul_effect(a::Foo, b::Bar) and mul_effect(a::Bar, b::Foo) yourself.
